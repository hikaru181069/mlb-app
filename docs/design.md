# Design Principles

## Philosophy

デザインは装飾ではない。
「新しい選手と出会う」という体験を、最も気持ちよく実現するための手段である。

## Concept

Discover体験はTinder × Apple Music、質感はLinear。

アプリの核となるDiscover画面は、カードとスワイプで偶然の出会いを生む体験を維持する。
その上で、タイポグラフィ・配色・モーションの精度はLinear級の洗練さを目指す。

お気に入り一覧や比較機能など「すでに何を探しているか分かっている」補助画面は、
Linear的なリスト／フィルタUIで効率よく使えるようにする。

## Reference

- Tinder / Bumble — スワイプによる直感的な出会い体験（Discover画面）
- Apple Music — 大きな写真・余白・滑らかなアニメーション（Discover画面）
- Linear — シャープなタイポグラフィ・ミニマルな配色・精度の高いモーション（全体の質感、補助画面のリストUI）

## UI Direction

### Discover画面（中心体験）

- カード形式のスワイプ操作を維持する
- 写真を主役にし、情報は最小限に留める
- タイポグラフィ・配色・モーションはLinear級の精度を追求する

### 補助画面（お気に入り・比較・検索など）

- リスト／グリッド形式で一覧性を重視する
- フィルタ・ソート・検索で目的の選手へ素早くたどり着けるようにする
- ダークモードを基本とし、アクセントカラーは最小限に絞る

## Keywords

Minimal / Sharp / Human / Fast / Premium
